# Polynomial Commitment Comparator

Демонстрационный web-инструмент для сравнения KZG, IPA и FRI в контексте zero-knowledge протоколов и рекурсивных доказательств.

## Что изменено в clean-версии

- Убран блок с напоминанием «Важно».
- Убран нижний пояснительный блок после расчетной таблицы.
- Добавлен компактный блок «Как формируется рекомендация» перед расчетными значениями.
- Логика рекомендаций сохранена без изменений.

## Финальная логика рекомендаций

- **KZG** выигрывает при `Минимальный размер proof` или `Минимальная внешняя проверка`, если trusted setup допустим и не требуется рекурсия/прозрачность.
- **IPA** выигрывает при `Рекурсивная проверка` или включенном параметре `Нужна рекурсивная проверка`.
- **FRI** выигрывает при `Прозрачность / STARK-like подход` или включенном параметре `Нужна прозрачная схема без SRS`.
- Если trusted setup запрещен, KZG получает сильный штраф.
- Если требуется рекурсия, KZG получает штраф из-за стоимости арифметизации pairings.
- Если требуется прозрачность, FRI получает приоритет.

## Структура проекта

```text
index.html   — структура страницы

```
