# Polynomial Commitment Comparator

Демонстрационный web-инструмент для сравнения KZG, IPA и FRI в контексте zero-knowledge протоколов и рекурсивных доказательств.

## Назначение

Инструмент не реализует криптографические протоколы KZG, IPA или FRI.  
Он показывает сравнительную модель по параметрам:

- размер полинома или вектора `n`;
- число полиномов `m`;
- число точек открытия `t`;
- число запросов FRI `q`;
- blowup factor для FRI;
- допустимость trusted setup;
- требование рекурсивной проверки;
- требование прозрачности;
- выбранный приоритет сравнения.

## Структура проекта

```text
index.html   — структура страницы
styles.css   — оформление интерфейса
data.js      — сравнительные данные по KZG, IPA и FRI
script.js    — расчет модельных оценок и рекомендаций
README.md    — описание проекта
```

## Как запустить локально

Откройте файл `index.html` в браузере.

Можно также запустить локальный сервер:

```bash
python -m http.server 8000
```

После этого открыть:

```text
http://localhost:8000
```

## Как опубликовать на GitHub Pages

1. Создать публичный репозиторий на GitHub.
2. Загрузить файлы `index.html`, `styles.css`, `data.js`, `script.js`, `README.md`.
3. Открыть настройки репозитория.
4. Перейти в раздел `Pages`.
5. В качестве источника выбрать ветку `main` и папку `/root`.
6. Сохранить настройки.

## Ограничения модели

Расчетные значения являются условными. Они не являются benchmark-результатами и не должны интерпретироваться как реальные размеры доказательств или время работы.

Модель не учитывает:

- конкретную elliptic curve;
- стоимость pairing в выбранной библиотеке;
- оптимизацию MSM;
- выбор поля;
- FFT/LDE-реализацию;
- конкретную хэш-функцию;
- параметры Fiat–Shamir transcript;
- особенности полной доказательной системы.

Цель инструмента — визуализировать компромиссы, описанные в дипломной работе: KZG дает compact openings, IPA удобнее для pairing-free рекурсии, FRI дает прозрачность и STARK-like архитектуру.
