# Polynomial Commitment Comparator

Демонстрационный web-инструмент для сравнения KZG, IPA и FRI в контексте zero-knowledge протоколов и рекурсивных доказательств.

## Изменения в minimal-версии

- Удалены карточки схем.
- Удалены текстовые блоки под карточками.
- Удалены подписи вида «криптографическая основа».
- Оставлены только входные параметры, рекомендация, скоринговые полосы и расчетная таблица.
- Логика рекомендаций сохранена.
